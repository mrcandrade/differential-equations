# Differential Equations

This repository contains projects and simulations related to differential equations, numerical methods, and computational modeling.

## Contents

- eqdiff2/ — interactive predator-prey simulation with 3D visualization
- PINNs/ — experiments with Physics-Informed Neural Networks
- output/ — generated outputs and artifacts
- questao1.c, questao2.c, questao3.c — C implementations related to the project

## Main project

The folder eqdiff2 includes:

- app.py — interactive Dash/Plotly simulator
- model.py — mathematical model and Euler integration logic
- simulador_patagonia.ipynb — explanatory notebook
- requirements.txt — dependencies

## How to run

### Web simulator

1. Go to the eqdiff2 folder
2. Install dependencies
3. Run the application
4. Open the browser at http://127.0.0.1:8050

### Notebook

Open the Jupyter notebook in the eqdiff2 folder.
